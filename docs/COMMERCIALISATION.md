# Commercialisation roadmap

The data model separates member payments from platform billing and supports organisation trials, founding-club entitlements, feature flags, usage metering, branding and ownership transfer. Initial founding-club access is not a claim that Stripe, SMS, WhatsApp, AI or other providers are free.

Before paid launch: define plans centrally; add VAT/tax and invoicing review; implement platform billing in Stripe test mode; test upgrade/downgrade/grace/cancellation; publish service levels and support boundaries; complete processor agreements, penetration testing and availability monitoring; and keep safeguarding/medical access outside commercial support impersonation.

Prices and entitlements must not be hard-coded across UI components. Commercial analytics remain aggregate and exclude child/sensitive content.
